# Changelog

## 3.1.0 — DeafDeep & UI refresh

- Template suara DeafDeep menjadi default baru, dengan pemetaan suara UI yang diperbarui.
- Navigasi bawah memakai tampilan backdrop blur adaptif pada Android dan fallback translusen pada iOS.
- Pemilihan preset satu nilai pada Setelan memakai popover kontekstual; daftar pilihan multi-channel Telegram tetap inline.
- Heading Hyperlink menggunakan font sistem.
- APK Android 64-bit ARM (`arm64-v8a`), minimum API 31, target API 36.
- Package Android `com.tradepilotnative`; `versionCode` 34.

Fitur dasar pasar, chart, Telegram, Gemini, paper trading, dan adapter exchange terdokumentasikan di [README](README.md) dan [panduan API](docs/API_SETUP.md).
